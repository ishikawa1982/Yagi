# Yagi 🐐 — アクション倉庫番

倉庫番（Sokoban）にアクション要素を加えた、ブラウザで遊べるパズルアクションゲームです。
ビルド不要・外部依存なしの **単一 HTML ファイル**。`index.html` をブラウザで開くだけで遊べます。

## 遊び方

ヤギ（🐐）を操作して、すべての **箱（俵）** を **目標（緑の円）** に押し込むとステージクリア。
全ステージをクリアすると勝利です。

## アクション要素

- **リアルタイム移動** — ターン制ではなく、キーを押しっぱなしでヤギが滑らかに走り続けます。
- **動く敵 👹** — 敵はマップ上を往復パトロール。**触れるとミス**（ライフ −1）。避けながら箱を運びましょう。
- **スコア & コンボ** — 箱を目標に入れるたびに加点。短時間に連続で決めると **コンボ倍率** が上がり、得点が跳ね上がります。ステージクリア・残ライフでボーナスも。

## サウンド & グラフィック

- **BGM / 効果音** — すべて **Web Audio API で手続き的に生成**（外部音源ファイルなし）。チップチューンのループBGMに加え、移動・箱押し・目標達成・コンボ・被ダメージ・クリアの効果音付き。HUDの **🔊 ボタン** で ON/OFF できます（ブラウザの自動再生規制のため、最初の操作で音が鳴り始めます）。
- **グラフィック** — キャラクター（ヤギ・鬼）や箱・壁・目標はすべて **Canvas 2D の自作ベクター描画**。歩行アニメ、発光する目標、鬼のオーラ、砂煙・スパークル・紙吹雪のパーティクル、画面シェイク、スコアのカウントアップなどの演出を搭載。高解像度（devicePixelRatio対応）でくっきり表示されます。

## 操作

### PC（キーボード）

| キー | 動作 |
| --- | --- |
| `←` `↑` `↓` `→` / `W` `A` `S` `D` | 移動（箱を押す） |
| `R` | 現在のステージをやり直す |
| `Enter` / `Space` | 開始・画面決定 |

### スマホ（タッチ）

- タッチ端末では画面下に **十字ボタン（D-pad）** と **やり直しボタン** が自動表示されます。
- 十字ボタンは **押しっぱなし** でヤギが連続移動します。
- タイトル／クリア／ゲームオーバー画面は **画面をタップ** すると次へ進みます。

## ルール補足

- 箱は **押すだけ**（引けません）。箱の先が壁・別の箱・敵の場合は押せません。
- 敵に触れるとライフが1減り、そのステージが最初からやり直しになります。
- ライフが0になるとゲームオーバーです。

## 起動方法

```
# リポジトリを取得後、ブラウザで開くだけ
open index.html        # macOS
xdg-open index.html    # Linux
```

または `index.html` をブラウザにドラッグ＆ドロップしてください。
